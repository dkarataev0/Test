# ЗИП ЛЮКС — сайт ZIP-систем

Статический сайт без сборки: открыть `index.html` в браузере или выложить папку на любой хостинг (Vercel, Netlify, GitHub Pages).

## Структура

| Файл | Что внутри |
|------|------------|
| `index.html` | Вся главная страница |
| `styles.css` | Дизайн-токены (цвета, шрифты) в `:root` и стили |
| `script.js` | Интерактив и `CONFIG` с ценами и контактами |
| `privacy.html` | Шаблон политики обработки данных |
| `favicon.svg`, `robots.txt`, `sitemap.xml` | Иконка и SEO |

## Разделы

1. **Главный экран** — сцена террасы, экран опускается ползунком.
2. **Гарантии** — короткая полоса доверия.
3. **Решения** — вкладки «Дом / Терраса / Пергола / Кафе»; кнопка переносит типовые размеры в конфигуратор.
4. **Сравнение** ZIP-экрана с рулонной шторой и маркизой.
5. **Технология** — схема с точками и раскрывающимся описанием деталей.
6. **Конфигуратор** — размер, ткань и цвет, управление, датчик, монтаж; живая цена и превью.
7. **Как работаем** — 5 шагов.
8. **Вопросы.**
9. **Заявка на замер** — маска телефона, проверка полей, текст из конфигуратора подставляется сам.
10. На телефоне снизу закреплена панель «Позвонить / Бесплатный замер».

## Что заменить перед запуском

- **Контакты-заглушки**: `+7 (000) 000-00-00`, `info@example.com`, «Ваш город» — в `index.html` (шапка, заявка, подвал, JSON-LD), `script.js` и `privacy.html`.
- **Цены** в `script.js → CONFIG`: ставка за м², доплаты за управление, датчик, тип монтажа, монтаж. Сейчас стоят ориентировочные значения — проверьте с поставщиком.
- **Отправка заявок**: `CONFIG.formEndpoint`. Пока пусто, заявка открывается в WhatsApp с готовым текстом.
- **Домен** в `robots.txt` и `sitemap.xml`.
- **Реквизиты** в `privacy.html`.
- **Фото**: вместо фотографий стоят иллюстрации. Реальные фото ваших объектов сильно повысят доверие — их стоит добавить в блок «Решения» и отдельной галереей.
