# LeadFinder — поиск клиентов на создание сайтов

Находит малый бизнес Краснодара **без сайта**, **только с соцсетями** или со **слабым сайтом**
и для каждой компании готовит контакты, тексты первого сообщения и индивидуальный макет сайта.

## Возможности

- **Поиск** по OpenStreetMap (бесплатно, без ключей): красота и здоровье, еда, авто и ремонт, магазины и услуги. Сетевые бренды отсекаются.
- **Проверка сайтов**: открывается ли, HTTPS и сертификат, адаптивность под телефон, скорость, SEO-теги, «свежесть» (год в подвале), устаревшая вёрстка, бесплатный конструктор. Итог — оценка 0–100 и список проблем человеческим языком.
- **Карточка компании** по клику: контакты с кнопками «Позвонить», WhatsApp, Яндекс Карты, 2ГИС; анализ сайта; карта; статус работы (Новый → Написал → Ответил → Клиент / Отказ) и заметки.
- **Сообщения**: WhatsApp/Telegram, письмо, скрипт звонка, напоминание. Учитывают нишу и найденные проблемы; ваше имя и телефон подставляются автоматически.
- **Макет сайта** под компанию: название, адрес, телефон, график, карта, услуги и цены по категории. 3 стиля, просмотр «компьютер / телефон», скачивание HTML.
- **Экспорт** всех лидов в CSV (открывается в Excel).

## Запуск

```bash
pip install -r requirements.txt
python -m leadfinder
```

Откроется браузер на http://127.0.0.1:8000. Нажмите **«Найти клиентов»** или **«Посмотреть демо»**.

Настройки через переменные окружения:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `LEADFINDER_CITY` | `Краснодар` | Город поиска |
| `LEADFINDER_DATA` | `./data` | Где хранится база (статусы и заметки) |

Параметры запуска: `--port 8080`, `--no-browser`.

## Как устроено

```
leadfinder/
  osm.py        поиск в OpenStreetMap (Overpass API, 3 зеркала)
  audit.py      проверка качества сайтов
  messages.py   шаблоны сообщений
  mockup.py     макет сайта (templates/mockup.html)
  storage.py    SQLite: компании, статусы, заметки
  app.py        API (FastAPI)
  static/       интерфейс
tests/          pytest + сохранённые образцы данных
```

Тесты: `python -m pytest`.

## Ограничения

- В OpenStreetMap компаний меньше, чем в 2ГИС/Яндексе, и не у всех есть телефон. Для компаний без контактов в карточке есть кнопки «Найти в 2ГИС» и «Яндекс Карты».
- Полный поиск с проверкой сайтов занимает несколько минут.
- Отзывы и цифры в макете — примеры-заглушки; это концепт для показа клиенту.
