# Картотека клиентов

Личный рабочий инструмент: по каждому клиенту в одном месте его проекты, ссылки и доступы. Найти нужное и скопировать можно за пару секунд (Ctrl/Cmd+K).

Без сборки и зависимостей: статические файлы. Запуск:

```bash
python3 -m http.server 8000   # затем открыть http://localhost:8000
```

Для работы нужен защищённый контекст (`https://` или `localhost`): без него браузер не даёт Web Crypto.

## Хранение и безопасность

- Данные лежат локально в IndexedDB браузера, на этом устройстве. Ничего не уходит в сеть (CSP: `connect-src 'none'`, шрифты подключены локально).
- Шифруется вся база целиком: AES-GCM, ключ из мастер-пароля через PBKDF2-SHA256, 600 000 итераций. В хранилище лежит только шифртекст, соль и IV.
- Мастер-пароль нигде не сохраняется. Ключ живёт в памяти как неизвлекаемый `CryptoKey`.
- Автоблокировка через 10 минут бездействия. Пароль скрыт, пока его не показали (и скрывается снова через 20 с).
- Скопированный пароль стирается из буфера через 30 секунд.
- Экспорт отдаёт тот же зашифрованный файл. Импорт просит мастер-пароль из файла.
- Пароли не попадают в URL, логи и `localStorage` (там только выбранная тема).
- Если забыть мастер-пароль, данные не восстановить. Делайте экспорт.

Чтобы получить доступ с телефона и компьютера, хранилище можно заменить на Supabase: достаточно переписать `vault.js`, шифрование на клиенте останется тем же.

## Горячие клавиши

`Ctrl/Cmd+K` или `/` поиск · `N` клиент · `P` проект · `A` доступ · `L` ссылка · `Shift+L` блокировка · `?` подсказка.
В поиске: `Enter` открыть, `Ctrl+Enter` копировать пароль или адрес. Поиск понимает неверную раскладку (`vjhjpjd` найдёт «Морозов»).

## Дизайн-план

Направление: картотечный индекс, а не «CRM с карточками».

**Палитра** (светлая / тёмная)

| Роль | Светлая | Тёмная |
|---|---|---|
| Фон / индекс | `#F1F2F4` / `#E6E8EB` | `#0F1114` / `#0A0C0E` |
| Лист дела | `#FFFFFF` | `#171A1E` |
| Текст / приглушённый | `#14181D` / `#566170` | `#E6E9ED` / `#929DAA` |
| Линии | `#D0D5DB` | `#2B3138` |
| Акцент (действие, фокус, выбранное) | `#1B4FE0` | `#86A3FF` |

| Опасность | `#B3261E` | `#FF8A7D` |

**Шрифты:** IBM Plex Sans (интерфейс) и IBM Plex Mono (всё, что копируют: логины, пароли, адреса, даты). Шкала: 12 / 13 / 14 / 16 / 20 / 28.

**Принципы**
1. Данные как образцы: всё копируемое набрано моноширинным шрифтом, клик по значению копирует его, значение на миг подсвечивается маркером.
2. Индекс и вкладки вместо карточек: буквенные разделители слева, выбранный клиент «вырастает» в лист дела, проекты это настоящие вкладки-закладки. Вместо теней тонкие линии.
3. Маркер только для того, что требует внимания: совпадения поиска, ближайшие продления, найденный доступ.

**Что поменял при проверке плана.** Первая идея: бумажные папки, штампы «ДЕЛО №», кремовая бумага. Отказался: это декор, он замедляет и выглядит как стилизация. Вторая: список слева и карточки проектов с тенями. Отказался: так выглядит любая CRM. Оставил только то, что работает на скорость: алфавитный индекс, вкладки-проекты, моноширинные «образцы» и маркер для внимания.
