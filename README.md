## Настройка заявок в Telegram

Токен бота хранится на сервере, а не в коде страницы, поэтому посетители его не увидят.

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` и получите **токен**.
2. Напишите своему новому боту любое сообщение (иначе он не сможет вам писать).
3. Узнайте свой **chat id**: откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найдите `"chat":{"id": ...}`. Для группы добавьте бота в группу; id будет отрицательным.
4. Разверните сайт на [Vercel](https://vercel.com) (импорт этого репозитория, без настроек сборки).
5. В Vercel → Project → Settings → Environment Variables добавьте:
   - `TG_BOT_TOKEN` — токен из шага 1
   - `TG_CHAT_ID` — id из шага 3
6. Сделайте Redeploy и отправьте тестовую заявку.

Если отправка не удалась (нет сети, бот не настроен), посетитель увидит кнопки
«Скопировать и открыть Telegram» и «Позвонить», а расчёт не потеряется.

## Как поменять

- **Цены.** В `assets/app.js` объект `PRICES`: пока там `null`, и калькулятор пишет «Цена по запросу».
  Укажите число (₽ за м² или пог. м), и появится ориентировочная стоимость.
- **Услуги.** В `assets/app.js` массив `SERVICES`: название, описание, единица, опции.
- **Фото «до/после».** В `assets/app.js` массив `BA_SCENES`: добавьте `before` и `after` с путями к фото.
- **Контакты.** Телефон и Telegram встречаются в `index.html`, `privacy.html` и `assets/app.js`.

## Локальный просмотр

```bash
npx serve .
```

Без Vercel отправка заявки не сработает, и вы увидите запасной вариант с копированием заявки.
