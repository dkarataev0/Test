# Сайт ZIP-систем ALUTECH

Статический одностраничный сайт: `index.html`, `styles.css`, `script.js`, `privacy.html`. Сборка не нужна — можно открыть `index.html` в браузере или выложить папку на любой хостинг (Vercel, Netlify, GitHub Pages).

## Что заменить перед запуском

- **Название компании** `ZIP STUDIO` — в шапке, подвале и `privacy.html`.
- **Контакты** — телефон, почта и адрес в подвале `index.html`.
- **`script.js` → `CONFIG`**: ставка за м², номер WhatsApp и `formEndpoint`. Пока `formEndpoint` пустой, заявка открывается в WhatsApp с готовым текстом.
- **Политика конфиденциальности** — реквизиты в `privacy.html`.
- **Фото** — сейчас вместо фотографий стоят иллюстрации. Лучше заменить их реальными фото ваших объектов.
- Проверьте факты (размеры, сроки, ветровой класс, гарантию) с вашим поставщиком.
